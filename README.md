# How far can light twist a shape?

Author: Michaël Perreault

An introduction, without equations, to the research paper *Affine length bounds the conformal excursion on a null cone: a sharp focusing inequality* (concept DOI [10.5281/zenodo.24572220](https://doi.org/10.5281/zenodo.24572220)). The paper has the proofs. This note has the idea, and it says which claims are proved and which are only computed.
